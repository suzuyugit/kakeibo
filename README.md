# 家計簿

毎日の収入と支出を記録して、旅行の日までに貯金がいくらあるかを見通す、個人用の家計簿アプリ（PWA）。
たびメモ（`/tabi-app/`）の旅行の支出（自分の負担分）は、たびメモの「家計簿に送る」→ 家計簿の「たびメモから取り込む」で入る。

- 公開先：https://suzuyugit.github.io/kakeibo/
- 仕様：[SPEC.md](SPEC.md)

```bash
npm install
npm run dev      # 開発サーバー
npm test         # テスト
npm run build    # 型チェック＋ビルド
```
